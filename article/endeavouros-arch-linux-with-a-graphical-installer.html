EndeavourOS: Arch Linux with a Graphical Installer

EndeavourOS serves as an accessible gateway to Arch Linux, combining the power and flexibility of a rolling-release distribution with an intuitive, user-friendly setup process. While pure Arch requires users to configure disk partitions, mount filesystems, and install system components manually via a command-line interface, EndeavourOS automates this setup using a graphical installer. By doing so, it eliminates the intimidating barrier to entry while preserving Arch’s minimal, terminal-centric philosophy and direct access to upstream software.

Arch Linux is renowned for its speed, simplicity, and bleeding-edge packages, but its manual installation process often deters beginners and busy professionals. Setting up pure Arch involves partitioning disks with command-line utilities, manually generating filesystem tables, bootstrapping base packages via pacstrap, configuring locale and network files in a chroot environment, and manually deploying a bootloader. This procedure demands significant time, technical knowledge, and meticulous attention to detail.

EndeavourOS bridges this gap primarily through the integration of the Calamares installer framework. Calamares provides a straightforward, step-by-step graphical interface that handles the complex parts of system initialization. Through a familiar wizard, users can configure keyboard layouts, set time zones, automate disk partitioning, and create user accounts in minutes.

To cater to diverse user preferences, EndeavourOS offers two distinct installation modes within Calamares:

  • Offline Installation: Installs a fully configured, lightweight XFCE desktop environment without requiring an active internet connection.
  • Online Installation: Allows users to choose from a wide selection of desktop environments and window managers—including KDE Plasma, GNOME, Cinnamon, MATE, Budgie, LXQt, and i3-wm—downloading the latest packages directly during installation.

Unlike some other Arch-based distributions that maintain separate repositories and delay package updates, EndeavourOS stays remarkably close to pure Arch. It relies directly on the official Arch Linux package repositories, ensuring users receive software updates, security patches, and kernel releases at the same time as standard Arch users. EndeavourOS maintains only a very small repository of its own, dedicated exclusively to themed artwork, mirror management utilities, and essential system maintenance scripts.

The distribution also bridges the post-installation learning curve through its custom "Welcome" application. Rather than replacing the command line with bloated software centers, the Welcome app serves as a guide for new users. It offers one-click shortcuts to update system mirrors, run updates via pacman or the yay AUR helper, and install proprietary hardware drivers.

By removing the friction of manual installation while retaining direct access to Arch repositories and the Arch User Repository (AUR), EndeavourOS delivers the pure Arch experience in a reliable, modern, and approachable format.
